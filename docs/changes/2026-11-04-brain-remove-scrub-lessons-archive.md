# Brain: remove a source, scrub a value, lessons at Finish, archive a brain

Spec `docs/superpowers/specs/2026-11-04-brain-followups-design.md` (PR 2 of 2), after `2026-11-04-brain-ask-verified-secrets.md`. The second half of the remaining llm-wiki harvest.

## What changed

- **Remove source** (`removeSource` in `sources.ts`, `brain:removeSource`): on the Sources tab, an open source (not a wiki mirror page) has a "Remove…" bar with a confirmation. The source, its original beside it and its assets folder are deleted, its capture is forgotten in `brain/state.json`, and only those paths are committed as `Brain: remove source <path>`. A `retract` job then runs `/retract <path>`: the pages citing it lose the claims only it backed, keep what other sources back (citation moved), update `sources:` and `last_updated`, and a page left empty is deleted. The file stays in the brain's git history; the bar says so. Refused while a job runs.
- **Scrub a value** (`scrub.ts`, `brain:scrub`): a password field under the findings on the Health card. Every occurrence of the value, its URL-encoded form and (from 8 characters) its base64 form in the brain's text files (`sources/`, `wiki/`, `index.md`, `log.md`, `brain/state.json`; pictures and binary originals untouched, files over 20 MB skipped) becomes `[REDACTED]`; a file named after the value is renamed; only the changed paths are committed as `Brain: scrub`, so a hand edit elsewhere stays an outside edit. The value never reaches telemetry, logs or the commit; the answer is a count, and the notice says history still holds the old text. Fewer than 6 characters is refused.
- **Lessons at Finish** (`sessionDigest.ts`, `FinishOptions.captureLessons`): a second Finish option, "Save what this task taught into the brain", off by default. Shellie reads the task's Claude Code transcripts (every Claude tab, closed ones included), keeps what the developer typed and what Claude said (tool calls, tool output, injected text and side chains left out; consecutive Claude turns joined), cuts each turn at 2,000 characters and the whole at 60,000, and adds it as a `task` source named `<slug>-session.md` through `addSource` (the secret scan applies; a duplicate or a refused digest is logged, never fails the Finish). A `lessons` job runs `/lessons <source>`, which writes `lesson-<yyyy-mm-dd>-<topic>.md` pages (0 to 7, never invented, each with the rule that generalises) and links them to the components they touch; the runner records the source as captured, as it does for a capture. A task whose Claude was never used adds nothing.
- **Job kinds**: `retract` and `lessons` take a source (`SOURCE_JOB_KINDS`), prompt `/<kind> <source>`, and queue no lint after them. `brain:run` accepts them; `brain.job` telemetry lists them.
- **Archive a brain** (`Brain.archived`, default false; `brain:update { archived }`): Archive and Restore on the card in Settings › Brains, archived brains listed apart under "Archived brains". An archived brain is out of the nav, is not the brain of any task (`BrainStore.forProject` skips it: no Context section, no `--add-dir`, no Brain tab, no close line), gets no scheduled refresh or digest, and refuses sources, jobs and refreshes with "This brain is archived; restore it in Settings › Brains first". Delete stays. `settings.brain` telemetry gains `archive` and `restore`.

## Known gaps

- Removing or scrubbing changes the working tree and makes a commit; git history keeps the old content. Rewriting history is not offered: delete the brain's folder and start again when a secret must be gone for good.
- A scrubbed source keeps its `sha256` frontmatter, so dropping the same original again is still refused as a duplicate.
- `/retract` is a skill run: a claim it cannot trace to the removed source stays; Shellie's broken-link check lists any link still pointing at the removed file.
- The session digest keeps text only: a lesson that lived in a tool's output (an error message Claude never quoted) is not in it.
- Archiving does not close an open brain terminal or stop a job already running; new jobs are refused.
