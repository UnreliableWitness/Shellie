# Rename to Shellie

Rename to Shellie (spec `docs/superpowers/specs/2026-10-18-rename-to-shellie-design.md`) implemented 2026-10-18 on `feature/rename-shellie`: names, icons, env vars (`SHELLIE_*`), `.shellie.yml`, `shellie.task.id`, `.shellie/task.md`, `shellie.*` UI prefs. Old names still work: `.miac.yml` when there is no `.shellie.yml`, `miac.task.id`, `MIAC_TELEMETRY=0`, `MIAC_TASK_ID` (set alongside), repos saved with `miacYmlFound`. First start copies the app's files from `<appData>/miac` (`src/main/migrate/`, marker `migrated-from-miac.json`, sentinel `migrating-from-miac` with at most 3 attempts; the old folder is never changed), moves live worktrees' `.miac/` to `.shellie/`, copies `miac.*` localStorage keys, and re-encrypts PATs with Shellie's key (macOS: one Keychain prompt for `miac Safe Storage`, 120 s timeout; Windows: MIAC's `Local State` key via DPAPI in PowerShell 5.1); a refused or failed read leaves the connection asking for the PAT. Verified live on macOS with seeded MIAC data (tasks, repo, prefs, task folder migrated; the unanswered Keychain prompt fell back to "enter it again"; a second start does nothing). The Squirrel id is `shellie`, so Windows MIAC installs need a one-time Shellie install. Known gaps: the Keychain Allow path and the Windows DPAPI path are unit-tested only (Windows checklist section 16).
