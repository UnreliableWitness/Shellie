# Git sign-in

Git sign-in (#82, 2026-10-20, `fix/git-auth`): fetch (setup, reopen) and push (Finish) to an https Azure Repos remote send the PAT of the repo's connection (else any connection in that organization) as an `http.<org url>.extraHeader` through `GIT_CONFIG_*` environment variables, never on the command line (`src/main/services/gitAuth.ts`), so a credential helper that cannot start from Shellie's console-less git no longer blocks them; when git still cannot sign in (`src/shared/gitAuth.ts` reads its stderr), the setup page and Finish say what to do, with an Update token button that opens the connection's new Update token form in Settings (Connections), or how to sign in once from a terminal for other remotes.
