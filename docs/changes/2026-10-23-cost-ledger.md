# Cost ledger

Cost ledger (spec `docs/superpowers/specs/2026-10-23-cost-ledger-design.md`) implemented 2026-10-23 on `feature/cost-ledger`: every AI request is one priced record (list price, EUR 0.92) in `<userData>/usage/ledger` (`src/main/ledger/`, monthly JSON-lines, `LedgerService` pass every 30 s), from Claude Code transcripts (`cc:<message id>`), OpenCode's database (`oc:`, any provider), Copilot CLI (`cp:<traceId>:<spanId>`) and Shellie's own `claude -p` PR-summary runs (`sh:`); vendor is claude (Claude Code, or OpenCode with provider anthropic) or copilot (Copilot CLI, or OpenCode with github-copilot). Attribution only goes up (none, repo, task) and is frozen at task; `billable:false` (tasks marked not billable) never lowers a budget. OpenCode usage now shows in the task's Usage tab. Home has two budgets, Claude and Copilot (`BudgetService`, one band each, alerts per vendor). Cost server (Settings > Cost server; `src/main/costServer/`): URL (https, or http on localhost), email and a company key encrypted with safeStorage; `GET /api/v1/hello` returns the developer's budgets (they then lock the Settings budget fields) and `POST /api/v1/records` upserts batches of at most 500 by id; `CostSender` sends in the background (15 s timeout, backoff to 30 min, a refused key stops sending until it changes), never blocking launch, task start, Finish or the Usage tab, and never sends prompts, responses, code, paths, cwd or terminal output (the work item title and type are in). Azure DevOps cost write-back is removed (2026-10-23): no `Custom.AI*` fields, usage comment, hourly sync, `writeCostToAdo` or PR cost line. Telemetry `ledger.records` (daily counts) and `costServer.*` in `docs/telemetry.md`. `src/main/costServer/costServer.integration.test.ts` runs connect, backfill, an outage and a wrong key against a real local HTTP server. Known gaps: one company key (any holder can post under any email); list prices, not the invoice; Copilot in VS Code, claude.ai and other machines are not seen, nor Copilot CLI outside a task; Claude Code deletes transcripts after about 30 days, so a late connect backfills that far; OpenCode cache writes priced as 5-minute; the Usage tab (OTLP) and the ledger can differ for a request OTLP missed (the ledger wins); Windows paths verified by CI only; the cost server itself (project 2) and vendor imports (project 3) are separate.
