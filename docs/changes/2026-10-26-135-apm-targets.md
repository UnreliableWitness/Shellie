# apm targets limited to apm.yml

apm targets limited to apm.yml (#135) on `agent/issues/135-opencode-refuses-to-start-when-apm-insta`: without an `apm:` list in `.shellie.yml`, the "Install agent packages" step only installs for the open tabs' harnesses that the repo's apm.yml declares (`targets:` or `target:`, a list, a string or comma list; `vscode` reads as `copilot`; `all`, no key or an unreadable apm.yml keep every tab target; `src/main/services/apmYml.ts`). A task whose tabs match none of them has no apm step; dropped targets are logged to the console. An explicit `apm:` still wins. Fixes OpenCode refusing to start on Claude-format agent files that APM copied into `.opencode/agents/`. Known gaps: APM's exact `targets` key shape checked from the issue, not the APM docs (no network); agent files earlier runs wrote stay in `.opencode/agents/`; not run live.
