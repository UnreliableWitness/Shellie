# The Brain accepts draw.io diagrams

A `.drawio` file dropped on the Brain screen or a task's Brain tab is now added as a source instead of being refused as unsupported (#220) on `agent/issues/220-second-brain-should-support-drawio`. `src/main/brain/convert/drawio.ts` reads both forms draw.io saves (plain `<mxGraphModel>` inside `<diagram>`, and the compressed form: base64 of raw deflate of the URL-encoded XML) with a small tag scanner, no new dependency. Each page becomes a `## <page name>` heading with a Mermaid `flowchart TD`: shapes are nodes, connections are `-->` arrows with their label (including labels drawn on the arrow), and containers such as groups and swimlanes are `subgraph`s. Below it every label is listed as plain text, with the HTML draw.io keeps in labels reduced to text, so nothing written in the diagram is lost when Mermaid cannot express a shape. A diagram without readable text gets a note and a warning instead of an error. The telemetry `format` of `brain.source.added` now has `drawio`. Not verified: real-world diagrams beyond the test fixtures (shapes, icons, colours, images and layout are not kept, only text and connections; tables and unusual containers may only show up in the label list), custom properties on `<object>` shapes, and Windows (pure Node, no platform code).
