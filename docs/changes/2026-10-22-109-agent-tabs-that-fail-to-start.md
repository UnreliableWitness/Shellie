# Agent tabs that fail to start

Agent tabs that fail to start (#109, 2026-10-22, `issues/109-agent-start-failure`): an OpenCode tab exited with code 1 at once because the worktree's `.opencode/agents/*.md` (written by the apm step just before) lists `tools` as Claude Code's comma string, which OpenCode 1.19 refuses ("Configuration is invalid at …"); Shellie only showed "Exited with code 1" and logged nothing. Now main diagnoses each agent tab's exit (`diagnoseExit` in `src/shared/terminalFailure.ts`, `TerminalFailures` in main, read 150 ms after the exit for late ConPTY output): a missing CLI (exit 127 or the shell's "not found"/"not recognized"), an invalid OpenCode config, or a non-zero exit within 30 s; the exit bar shows what happened, the program's line and what to do (install hint, Restart), and for OpenCode a "Start without project config" button (`OPENCODE_DISABLE_PROJECT_CONFIG=1`, until the next Restart). Telemetry `terminal.failed` / `terminal.exitedEarly` (kind, reason, exit code, run time; never output) and a spawn failure as an exception. Known gaps: Shellie does not rewrite the agent files apm writes; Windows wording of a missing CLI and a real crash of each CLI are unit-tested only.
