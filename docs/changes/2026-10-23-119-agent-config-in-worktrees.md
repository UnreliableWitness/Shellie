# Agent config in worktrees

Agent config in worktrees (#119, 2026-10-23, `issues/119-copy-agent-config`): the `copy` setup step also copies agent config files that exist in the main checkout but are not tracked by git (`AGENT_CONFIG_PATHS` in `SetupRunner.ts`: `opencode.json`, `opencode.jsonc`, `.opencode/`, `.mcp.json`, `.claude/settings.local.json`, `.vscode/mcp.json`), logged as "copied X (agent config)"; tracked files arrive through git and are never overwritten, symlinks are skipped, and `copyAgentConfig: false` in `.shellie.yml` (default true) or unticking the task's copy option turns it off. These files may hold tokens and now land in worktrees, the same trust level as the `.env` files `copy:` handles. Applies to reopen too (also other repos). Unit-tested only; not run in the live app.
