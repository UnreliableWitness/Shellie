# Each repo can set its own Claude Code and OpenCode start command

Each repo can set the command its Claude Code and OpenCode tabs start with (#191) on `agent/issues/191-choose-harness-startup-command`. Settings > Repositories has an "Agent commands" section under every repo with two free-text fields, "Claude Code command" and "OpenCode command"; an empty field means the plain `claude` or `opencode`, as before. The command runs in the user's own shell (a login shell on macOS, PowerShell on Windows), like the Run and Setup tabs, so `claude --permission-mode acceptEdits` works as written. Shellie still appends its own flags after the Claude command (session id, resume or continue, extra folders, theme settings, the task context as system prompt), so the field holds only the user's part. The value is stored on the repo in state.json (`agentCommands`, optional, so older files load as they are) and never sent in telemetry. On Windows a set command always runs through PowerShell, skipping the direct `claude.exe` start. Known gaps: Copilot CLI and the choice of which tabs open are not per repo (the latter stays the global "Agents and terminals" setting); there is no `.shellie.yml` key for it, so a cloned repo cannot choose what runs on the user's machine; the command is not checked, so a wrong one fails in the terminal tab with the shell's own error; the PR summary still uses plain `claude`; not checked in the running app, and Windows only through unit tests.
