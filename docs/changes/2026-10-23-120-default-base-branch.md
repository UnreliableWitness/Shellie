# Default base branch

Default base branch (#120, 2026-10-23, `issues/120-default-base-branch`): `.shellie.yml` without `base:` (or no file) no longer means `main`; `loadShellieConfig` takes the repo's real default branch from `GitClient.defaultBaseRef` (origin/HEAD, origin/main|master, local main|master, else the current branch), so Start, New task and setup's fetch use `origin/master` in an older repo; an explicit `base:` still wins. A fetch of a branch origin lacks says "origin has no branch 'main'. This repo's default branch is 'master'; set `base: master` in .shellie.yml" instead of git's raw error. A repo registered without a file keeps its stored `baseBranch` only while `origin/<it>` or the local branch exists; a stale one (an old `main` in a master repo) falls back to the detected default and is corrected in the store by `repos:refresh` and `repos:config`.
