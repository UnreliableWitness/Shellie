# Time tracking

Time tracking (spec `docs/superpowers/specs/2026-10-16-time-tracking-design.md`) implemented 2026-10-16 on `feature/time-tracking`: Shellie active time counts while the window is focused, the task is on screen and the system idle time is under the idle timeout (lock and sleep are excluded). Agent time comes from Claude Code (`claude_code.active_time.total`, type `cli`, via the OTLP metrics that are now exported), Copilot span durations, and an estimate from OpenCode terminal output. Realistic time is the union of Shellie and agent time; wall clock counts working hours only. Finish has a "Time spent" slider that starts at the measured value and books the chosen one. The Sprint page has a "Spent / est." column: local time, or Azure DevOps Completed Work for items without a local task; the estimate is Original Estimate, else the baseline taken at the first Start, else Remaining + Completed; parents roll up their children. The Usage tab has a Time card, the Done page shows "Time booked" with Retry, there is a time CSV export, and Settings has a Time tracking section. The opt-in setting `writeTimeToAdo` (default off) adds the booked hours (in steps of 0.25 h) to Completed Work and lowers Remaining Work at Finish; a re-finish writes only the difference.
