# Claude budget

Claude budget (spec `docs/superpowers/specs/2026-10-19-claude-budget-design.md`) implemented 2026-10-19 on `feature/claude-budget`: (a Copilot budget joined it on 2026-10-23, see the cost ledger) a "Claude budget" band on Home under Stats shows this budget month's Claude spend against `claudeBudget.monthlyEur` (Settings > Claude budget; month start day 1-28), with today's spend next to it against a daily allowance (what is left of the budget at the start of today over the days left including today; red when today is over it, no allowance without a budget, #85), a forecast (from day 4), a burn-down, daily bars stacked by model (outside-Shellie part hatched) and per-model totals; ‹ › step through earlier months. Data comes from every Claude Code transcript on the machine (`~/.claude/projects`, `CLAUDE_CONFIG_DIR` honoured, deduped by message id, 5m/1h cache writes priced apart; 1-hour cache writes cost 2x input; Claude Code writes several lines per message id and the copy with the largest tokens is kept) and OpenCode's `opencode.db` (read-only `node:sqlite`; only `providerID` `anthropic` counts, Claude through GitHub Copilot counts in the Copilot budget since 2026-10-23, other providers are listed as "Not in a budget"; this budget keeps its own rollup, the ledger is separate and priced identically), rolled up in `<userData>/usage/budget.json` by `src/main/budget/` (pass at launch, every 30 s and on focus). Alerts at 80%, forecast over and 100%, once per budget month. `node tools/budget-check.mjs <YYYY-MM-DD>` sums a day per model straight from the transcripts for comparison; verified equal to `budget.json` (requests, input and output tokens per model) on 2026-10-19. Known gaps: list prices, not the company invoice; other machines and claude.ai are not counted; OpenCode cache writes priced as 5-minute; Windows paths verified by CI only; Claude Code deletes transcripts after about 30 days (`cleanupPeriodDays`), so history from before Shellie first ran only goes back that far.
