# The + New terminal button stays visible in a narrow window

The + New terminal button now sits outside the tab row's scrolling area, right after it, so it stays in view however many tabs are open (#215) on `agent/issues/215-icon-to-open-additional-terminals-is-hid`. Before, it was a child of the `.tabrow` tablist in `src/renderer/components/TerminalTabs.tsx`, which scrolls sideways with a hidden scrollbar when the tabs do not fit next to the environment, branch and cost chips; on a small window the + scrolled out of sight and there was no way to open another terminal. A new `.tabs` wrapper in `src/renderer/styles/shell.css` holds the scrolling tab row and the +. The Run chips stay inside the scrolling row, so the + now comes after them instead of before them. Not verified: the layout in a real narrow window (jsdom has no layout; the test checks only that the + is outside the tablist), Windows and Linux title bars. No telemetry change.
