# The Brain accepts XML files

A `.xml` file dropped on the Brain screen or a task's Brain tab is now added as a source instead of being refused as unsupported (#252) on `agent/issues/252-adding-xml-file-to-the-brain-should-be-s`. `src/main/brain/convert/xml.ts` keeps the text as it is in an ```` ```xml ```` code block (a leading byte order mark dropped, the fence longer than any backtick run in the file so the content cannot close it); the original `.xml` is stored beside it under `sources/` and opens with Open source. A blank file is refused like a blank `.txt`. The line beside the source reads `XML · <root>` with the root element's name instead of a word count. The telemetry `format` of `brain.source.added` now has `xml`. Not verified: very large XML files (no size limit or truncation), XML in encodings other than UTF-8, and Windows (pure Node, no platform code).
