# Faster setup and APM

Faster setup and APM (spec `docs/superpowers/specs/2026-10-16-fast-setup-and-apm-design.md`) implemented 2026-10-16 on `UnreliableWitness/fix-npm-ci-apm`: setup commands no longer block the task; they run in a Setup tab (a `run` tab with `setupCommands`, last in the row, never restarted by itself) once the terminals start. When the commands include `npm ci`, macOS clones the main checkout's `node_modules` in one APFS `clonefile` call (JXA via `osascript`, `Platform.cloneDir`) if npm's hidden lockfile matches the worktree's `package-lock.json` (`nodeModules.ts`), and `npm ci` is then left out; Windows has no `cloneDir` yet. A repo with an `apm.yml` gets an "Install agent packages" step before the terminals: `apm install --target <t>` per harness of the tabs setup opens (`claude`, `copilot`, `opencode`), overridable with `apm:` in `.shellie.yml` (`false` or a list); apm missing is a warning.
