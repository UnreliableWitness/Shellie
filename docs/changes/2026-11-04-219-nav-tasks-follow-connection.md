# The nav's task list follows the project switcher

The task list in the left nav, both the open tasks and the Done section with its count, now shows only the active project's tasks (#219) on `agent/issues/219-swapping-connection-should-swap-tasks-as`. Before, switching from one project to another in the project tile still listed every task of every connection, so the 'iml hub' project showed the 'dxp' tasks. `groupTasks` in `src/renderer/components/TaskNav.tsx` takes the active connection and keeps a task when `inConnection` (new in `src/shared/workspaces.ts`) says so: the task's connection (its own, else its home repo's, as `taskConnectionId` already worked out) is the active one, or the task has no connection at all, like a blank task in a repo not linked to a project; those show under every project. The store keeps all tasks, so attention, Finish and the other screens are unchanged, and while a task page is open the active connection is that task's, so the open task never drops out of the list. Home's My tasks stays across all projects, like the rest of Home. Not verified: in the running app, and on Windows. No telemetry change.
