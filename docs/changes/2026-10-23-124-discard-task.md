# Discard task

Discard task (#124, 2026-10-23, `issues/124-discard-task`): a trash icon beside "Finish task" in the nav (under the rail's Finish, tooltip "Discard task"; beside Finish in Focus without the nav) opens a `ConfirmBar` on the task's page (`DiscardBar`) that names each workspace's folder and branch, the terminals it closes, the commits no remote has (`git rev-list <branch> --not --remotes <base>`, `GitClient.branchCommits`) and uncommitted files (then the button reads "Discard anyway"), and that nothing is pushed, booked, made into a PR or written to the work item. `tasks:discard` (ready tasks only; setting up, setup failed and finishing are refused, a failed setup keeps Cancel setup) closes the terminals, removes every workspace on the task's branch with Finish's `removeWorkspace` (one on another branch stays) and deletes the task and its `review/<taskId>.json`; a held folder goes to the store's `discardedCleanup`, which `WorktreeCleanup` retries with the done tasks' leftovers and drops once a live task uses that path again. The AI cost data is kept on purpose, since the money was spent: usage records keep their task id in the usage store and the Claude budget still counts them (it reads the transcripts); time records stay too. Known gap: Home's week/month stats and the per-task Usage CSV go by task, so a discarded task's cost no longer shows there.
